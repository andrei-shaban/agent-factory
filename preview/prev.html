Состояния интерфейса

Первоклассные объекты панели: оператор всегда понимает, что происходит с соединением, раном, формой и данными.

Reconnecting

SSE потерян, идёт восстановление по Last-Event-ID.

Реконнект. Буферизуем события, не теряем HITL-контекст.

Offline-alive

Вкладка была неактивна, ран живёт на бэкенде.

Ран продолжался без вкладки. Восстановлено из чекпоинта и Streams.
offline-alive checkpoint restored

Сценарии не найдены
У вашего профиля нет AD-групп для отображения каталога. Обратитесь к администратору Keycloak/LDAP.

Error boundary

Локальный сбой UI без потери бэкенд-рана.

Не удалось отрисовать компонент HITL
Ран продолжает исполняться. Отправьте diagnostic snapshot в Sentry и попробуйте восстановить ленту.

Loading / skeleton

Первичная загрузка каталога или истории.

HITL danger

Форма содержит критичные расхождения или destructive hint.

Внимание: операция изменяет документ в АРМ. Требуется явное подтверждение и idempotency-key.
destructiveHint idempotentHint

Dry-run

План исполнения без побочных эффектов.

Dry-run: ocr → extract → totals → hitl. Нода post будет пропущена.

Deprecated scenario

Сценарий помечен lifecycle: deprecated, запуск ограничен.

deprecated supersedes: legal-risk-scoring@1.0.0

Отображается в истории, но не доступен для новых запусков без явного административного решения.
